В рамках реализации стратегической инициативы по развитию цифровых сервисов и автоматизации процессов обработки клиентских данных требуется согласовать взаимодействие с внешним сервисом BalancePlatform (KYCMania) для распознавания паспортных данных через API.

Планируется интеграция с веб-ресурсом https://lk.kycmania.ru
 (включая все производные страницы и редиректы), а также с API сервиса по адресу https://api.kycmania.ru/api/v1/requests/{{REQUEST_UUID}}
. Взаимодействие будет осуществляться по защищенному протоколу HTTPS (TLS 1.2+), с использованием REST API и формата данных JSON.

В рамках интеграции предполагается передача изображений документов (паспортов) и получение структурированных данных (ФИО, серия и номер документа, дата рождения и др.), что относится к категории персональных данных. Использование данного сервиса необходимо для автоматизации KYC-процессов, сокращения времени обработки заявок, снижения ошибок ручного ввода и повышения качества клиентского сервиса.

Просим согласовать:

доступ к домену lk.kycmania.ru (включая все поддомены и производные ссылки);
доступ к API api.kycmania.ru, включая endpoint /api/v1/requests/{{REQUEST_UUID}};
разрешение исходящих соединений по протоколу HTTPS (TCP 443) из внутреннего контура.
